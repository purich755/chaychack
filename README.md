# ЧайЧак stories — демо главной страницы

Демо-сайт «Дома татарской продукции» (Казань, Мартына Межлаука, 6). Одна страница — визит гостя:
капка → «Рәхим итегез!» → чай → чак-чак → полка → сандык → күчтәнәч → stories → табын → рәхмәт → адрес → «Сау булыгыз!».

## Запуск

- Двойной клик по `index.html` — работает и так (нужен интернет для шрифтов, GSAP, Lenis, Matter.js и карты).
- Или локальный сервер: `node tools/serve.mjs 8270` → http://localhost:8270/
- На любом статическом хостинге — просто загрузить папку (без `raw/`, `tools/`, `node_modules/`).
- Живая версия: https://purich755.github.io/chaychack/ — деплой на GitHub Pages через `.github/workflows/pages.yml`
  при каждом пуше в `main` (в публикацию идут только `index.html` и `assets/`).

## Структура

```
index.html
assets/css/base.css       токены палитры, типографика, кнопки, арки, reveal, шапка, док, курсор
assets/css/sections.css   стили блоков 0–11 по порядку
assets/js/main.js         Lenis + ScrollTrigger, интро «Капка», шапка, док, меню, курсор, статус, reveal
assets/js/scenes.js       «Три глотка», синий чай, сандык + гравировка, полка «Күчтәнәч», счётчики, отзывы
assets/js/chakchak.js     вкладки и физическая горка (Matter.js грузится лениво)
assets/js/stories.js      данные 6 групп и просмотрщик; последним вызывает CC.boot()
assets/svg/               тюльпан (favicon), уголки и замок сундука, эталон арок
assets/img/, assets/video/
tools/                    сбор фото (Telegram, Яндекс.Карты), сборка ассетов, скриншоты, аудит
```

Порядок инициализации: каждый модуль регистрируется через `CC.on()`, `stories.js` вызывает `CC.boot()` —
сцены создаются сверху вниз, затем reveal, затем `ScrollTrigger.sort()` и `refresh()`.

Все фото — реальные, скачаны локально, хотлинков нет.

  дегустация на шпажках, чак-чак в коробках, сандыки в лавке, наборы, пряники, «Коробка счастья».
- **Telegram t.me/s/TatarTeaStories (800 px)**: сандыки (открытые, с гравировкой «Бәхет, мәхәббәт, бәрәкәт!»),

- **Видео**: 5,6 с из ролика печи (пост TG), 600×900, 1,2 МБ, без звука. Кадр самовара «Гигант» — из ролика о «Питрау-2026».
- VK закрыт для ботов — не использовался.

## Что сделано иначе, чем в брифе (и почему)

1. **Сундук — золотая жесть с малахитовыми ромбами, а не коричневое дерево.** Так выглядят их настоящие сандыки
   на всех фото; деревянная — только планка под гравировку и внутренность крышки (бархат).
2. **Полка «Күчтәнәч»**: фото съедобных букетов, мыла и свечей в источниках нет — они перечислены в карточке-бирке №9
   «Ещё на полке». Вместо них карточка «Пряники ручной работы» (реальная новинка из Telegram).
3. **Вкладка «Шоколадный»** показывает фото дегустации, где на шпажках и классический, и шоколадный чак-чак:
   отдельного фото шоколадного чак-чака нет.
4. **Мобильный сандык**: закрепляется только сцена с сундуком (+=120 %), форма гравировки идёт после неё.
5. Фото из Telegram — максимум 800 px, поэтому карточки ≤ 800 px (а не 1000).
